# ติดตามสายสัญญา Refinance

เว็บแอปหน้าเดียว (ไม่มีเซิร์ฟเวอร์) สำหรับดูว่าแต่ละสัญญาถูก ref ต่อกันมากี่ทอด และแต่ละทอดทำสัญญาวันที่เท่าไหร่

ข้อมูลไม่ถูกเก็บไว้ในเว็บ ผู้ใช้อัปโหลดไฟล์ในหน้าเว็บทุกครั้ง ไฟล์ถูกอ่านในเบราว์เซอร์ของผู้ใช้เท่านั้น ไม่ถูกส่งไปที่อื่น

## ไฟล์ในโฟลเดอร์นี้
- `index.html` ตัวเว็บแอปทั้งหมด (ไฟล์เดียว)
- `.nojekyll` บอก GitHub Pages ให้ใช้ไฟล์ตามที่มี ไม่ต้องประมวลผลผ่าน Jekyll

## วิธี deploy บน GitHub Pages
1. สร้าง repository ใหม่บน GitHub (เช่น `contract-monitor`)
2. อัปโหลดไฟล์ `index.html`, `.nojekyll`, `README.md` ไปที่ root ของ repository (ปุ่ม Add file > Upload files)
3. ไปที่ Settings > Pages
4. ที่ Source เลือก `Deploy from a branch` แล้วเลือก branch `main` โฟลเดอร์ `/ (root)` กด Save
5. รอประมาณ 1-2 นาที แล้วเปิดที่ `https://<ชื่อผู้ใช้>.github.io/<ชื่อ repository>/`

หมายเหตุ: repository ที่เป็น private ใช้ GitHub Pages ได้เฉพาะบางแพลนของ GitHub ถ้าไม่ต้องการให้ใครเปิดหน้าได้ ให้ตรวจเงื่อนไขของแพลนก่อน ตัวหน้าไม่มีข้อมูลสัญญาอยู่ข้างใน แต่ใครมีลิงก์ก็เปิดหน้าเปล่าได้

## วิธีใช้
1. เปิดหน้าเว็บ กดปุ่ม "อัปโหลดข้อมูลเดือนใหม่" แล้วเลือกไฟล์ `.xlsx` หรือ `.csv` (ไฟล์ 7.7 แสนแถวใช้เวลาอ่านประมาณ 10 วินาที, CSV เร็วกว่าเล็กน้อย)
2. เลือกโหมดช่วงเวลา (ตั้งต้นคือ "สัญญาแรกอยู่ในช่วง และแสดงสัญญาล่าสุด ณ สิ้นช่วง") แล้วเลือกช่วงเดือน มีโหมดอิงสัญญาแรกหรือสัญญาล่าสุดจริงของสายให้เลือกด้วย และมีตัวกรองอื่น ๆ
3. กด Export Excel ไฟล์ที่ได้มีเฉพาะข้อมูลที่แสดงอยู่ และมีชีตเงื่อนไขที่ใช้กรอง

หลังรีเฟรชหน้า ต้องอัปโหลดไฟล์ใหม่ทุกครั้ง

## รูปแบบไฟล์ที่รองรับ

| NL_CostAndInsurence | ยอดจัดบวกประกัน | ใช่ |
| NL_CloseDate | วันที่ปิด | ใช่ |

| AgingGroupCompanyName | ชั้นหนี้ ณ ตอนปิด | ใช่ |

| NL_BranchName | สาขา | ใช่ |

## กติกาที่ใช้
- การเชื่อมสาย (ค่าเริ่มต้น): ต่อสายเฉพาะสัญญาประเภทปรับปรุงโครงสร้างหนี้ สัญญาที่เป็นรีไฟแนนซ์หรือสัญญาใหม่เริ่มสายใหม่เสมอ ดังนั้นสัญญาแรกของสายปรับโครงสร้าง คือสัญญาที่ถูกนำมาปรับโครงสร้าง และใช้ยอดจัด+ประกันของสัญญานั้น เลือกแบบ "ทุกประเภทที่ ref" ได้
- 1 แถวในตาราง คือ 1 สายสัญญา นับจากสัญญาล่าสุดย้อนไปถึงสัญญาแรก
- โหมดตั้งต้น: สัญญาแรกของสายต้องอยู่ในช่วงที่เลือก และแสดงสัญญาล่าสุดของสายที่เปิดไม่เกินสิ้นช่วง สัญญาที่ ref ต่อหลังสิ้นช่วงแสดงแยกในคอลัมน์ "ref ต่อหลังสิ้นช่วง"
- ถ้าเลขสัญญาซ้ำ ใช้แถวแรก
- ถ้าสัญญาอ้างอิงกันเองเป็นวง ใช้สัญญาที่เดือนเก่ากว่าเป็นสัญญาแรก
- ตัวกรองประเภทสัญญาและประเภทสินเชื่อใช้ค่าของสัญญาล่าสุด
- ในไฟล์ export คอลัมน์ "ครั้งที่ k" คือสัญญาก่อนหน้าที่ถูก ref (ครั้งที่ 1 = สัญญาแรก) ไม่รวมสัญญาปัจจุบัน ซึ่งอยู่ในคอลัมน์ "สัญญาล่าสุด" แล้ว
- วันที่ ref คือ NL_ContractDate ของสัญญานั้น ถ้าไม่มีคอลัมน์นี้ ใช้วันที่ปิดของสัญญาก่อนหน้า
- ยอดจัด+ประกันในตารางสรุป ใช้ของสัญญาแรก
- ส่วนวิเคราะห์เกณฑ์อนุมัติ: Nano Finance และ Personal Unsecured Loan เกณฑ์ 20,000 บาท ประเภทอื่นเกณฑ์ 55,000 บาท (เกิน = มากกว่าเกณฑ์) สินเชื่อเงินด่วน (จำนำทะเบียนเล่ม) อนุมัติโดยสาขาทั้งหมด ไม่แยก ใช้ประเภทสินเชื่อของสัญญาล่าสุด และเลือกได้ว่าจะใช้ยอดของสัญญาแรกหรือสัญญาล่าสุด

## หมายเหตุทางเทคนิค
- ใช้งานได้บน Chrome, Edge, Safari และ Firefox รุ่นใหม่ (ต้องรองรับ `DecompressionStream`)
- โหลดฟอนต์ IBM Plex จาก Google Fonts ถ้าออฟไลน์จะใช้ฟอนต์ของเครื่องแทน
- ไม่มีไลบรารีภายนอก การอ่านไฟล์ .xlsx และสร้างไฟล์ Excel เขียนไว้ในหน้าเดียวกัน

## ธีมและการแสดงผล
- เลือกธีมได้ที่มุมขวาบน (ตามเครื่อง, สว่าง, มืด, พาสเทล 5 สี) ระบบจำค่าที่เลือกไว้ในเบราว์เซอร์
- เลือกคอลัมน์ที่แสดงในตารางได้ และเลือกคอลัมน์/การแยกแถวของตารางผลงานจัดเก็บได้ ค่าที่เลือกถูกจำไว้ในเบราว์เซอร์ของเครื่องนั้น
